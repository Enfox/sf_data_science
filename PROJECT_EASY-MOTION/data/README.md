# Данные

В папке находятся копии двух видео из четвёртого спринта. Исходники не редактировались.

| Файл | Происхождение | Формат |
| --- | --- | --- |
| `reference_video.mp4` | Референс, предоставленный для проекта; автор исходной публикации и её URL не указаны | MP4 / H.264, 720 × 1280, 60 FPS, 180 кадров, 3 с |
| `my.mp4` | Запись повторения движения, предоставленная автором проекта | MP4 / H.264, 480 × 854, 30 FPS, 120 кадров, 4 с |

Для корректного указания источника референса перед публичной публикацией нужно добавить
автора и ссылку на исходное видео, если они известны. Проект не заявляет авторство на референс.

В референсе почти чёрный кадр № 43 (нумерация с нуля, около 0.717 с).
В этом кадре спортсмен не найден. Он не попадает ни в одну из двух используемых сеток
сопоставления. Всего спортсмен найден в 179 из 180 кадров референса и во всех 120 кадрах повторения.

После чтения кадр имеет формат `uint8[H, W, 3]` в RGB. На вход нейросети подаётся
`float32[3, H, W]` со значениями от 0 до 1. Результат — 17 пар координат и score точек.
Координаты сохраняются в исходном разрешении каждого видео.

Эти два ролика — демонстрационные данные. Они не являются обучающей или независимой
тестовой выборкой. Для обучения понадобились бы размеченные изображения, рамки людей,
координаты ключевых точек и признаки их видимости. Такой набор в этом проекте не создавался.

Контрольные SHA-256 сохранены в [`results/summary.json`](../results/summary.json).
