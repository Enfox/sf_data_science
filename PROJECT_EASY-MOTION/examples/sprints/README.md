Здесь сохранены учебные этапы, из которых вырос финальный проект. Для знакомства
с готовой программой начните с [основного примера](../01_video_comparison.ipynb).
Архив пригодится для разбора отдельных шагов и демонстрации развития решения на защите.

| Спринт | Ноутбук | Что рассматривается | Входные данные |
| --- | --- | --- | --- |
| I | [Ключевые точки и скелет](sprint_1/REAL_CV_1_Keypoint_RCNN.ipynb) | Применение Keypoint R-CNN к фотографии | Изображение из задания рядом с ноутбуком |
| II | [Сравнение двух поз](sprint_2/REAL_CV_2_Pose_Comparison.ipynb) | Аффинное совмещение, косинусное сходство и взвешенное L1 | Референс и `my.jpg` рядом с ноутбуком |

## Как открыть и повторить расчёты

1. Установите зависимости из корневого `requirements.txt` по [инструкции проекта](../../README.md).
2. Откройте нужный ноутбук в VS Code/Jupyter и выберите Python из окружения проекта.
3. Выполните **Restart Kernel → Run All**. Рабочей папкой ядра может быть корень
   `PROJECT_EASY-MOTION` или папка выбранного ноутбука.

Во всех этапах применяется готовая Keypoint R-CNN с весами COCO_V1, без дообучения.
Первое получение весов требует интернета. Для сохранения видео в спринтах III и IV
нужен FFmpeg в PATH. На CPU обработка видео выполняется дольше, чем на GPU.

Сохранённые ноутбуки содержат таблицы и рисунки; видео также встроены в ноутбуки
спринтов III и IV. Для воспроизведения встроенного видео используйте локальный
просмотрщик ноутбуков. Повторный запуск создаёт `outputs/` внутри соответствующего
спринта. Эта папка содержит восстанавливаемые результаты и кэш, поэтому исключена
из Git. Отдельные HTML-экспорты, окружения и копии материалов курса сюда не входят.

## Как читать результаты

В ранних спринтах показано **косинусное сходство**: больше означает ближе.
В спринте IV и финальном проекте основная косинусная метрика — **расстояние**
`1 − сходство`: меньше означает ближе. Взвешенное L1 измеряется в пикселях референса.
Числа разных спринтов относятся к разным данным и не являются рейтингом моделей.
Расстояния после аффинной подгонки не оценивают правильность спортивной техники.

Исходные учебные ноутбуки сохранены в папках REAL-CV-1…REAL-CV-4 вне репозитория.
В этих копиях адаптированы пути и инструкции запуска для общей структуры проекта.
Референс фотографии взят из задания Skillfactory, фото и видео повторения предоставлены
автором проекта. Ссылки на исходные публикации референсных видео не были предоставлены.
