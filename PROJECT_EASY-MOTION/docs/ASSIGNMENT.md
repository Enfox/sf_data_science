# Соответствие заданию спринта V

Рекомендуемая структура адаптирована к небольшому учебному проекту. В тексте задания
упомянуты четыре модуля, но перечислены три назначения. Четвёртый пакет здесь выделен
под визуализацию, чтобы не смешивать её с данными, моделью и метриками.

Все четыре пакета в `src/` не импортируют друг друга. Их совместное использование
организует вспомогательный скрипт `scripts/pipeline.py`. Пакет `easy_motion`
содержит только расчёты, не зависящие от конкретного загрузчика или нейросети.
Названия `MyProject`, `myproject_data` и `myproject_models` из задания заменены
на соответствующие имена проекта: `easy_motion`, `easy_motion_data`, `easy_motion_models`.

| Требование | Где выполнено |
| --- | --- |
| Код в `src/`, независимая от данных и модели математика | `src/easy_motion/metrics.py` |
| Модуль данных с классом набора данных | `VideoDataset` в `src/easy_motion_data/video.py`, экспорт через `__init__.py` |
| Модуль нейросети | `PoseEstimator` в `src/easy_motion_models/pose.py`, экспорт через `__init__.py` |
| Пример в Jupyter | `examples/01_video_comparison.ipynb` |
| Изображения | `images/` |
| Основной скрипт | `scripts/main.py` |
| Вспомогательный сценарий | `scripts/pipeline.py` |
| Скелеты двух людей и метрики на видео | `results/relative/comparison.mp4`, `results/realtime/comparison.mp4` |
| Цели, данные, этапы | `README.md` |
| Формат входа и преобразования | `data/README.md`, `docs/METHOD.md` |
| Валидация и эксперименты | `docs/EXPERIMENTS.md`, `tests/` |
| Презентация по шаблону | `presentation/Easy_Motion.pptx` |
| Файлы для воспроизведения | Данные, исходники, зависимости, ноутбук и сохранённые результаты |

В критериях встречаются слова «задача рекомендаций», «оборот», «таблицы для обучения».
Они не описывают данный проект. Вместо выдуманных значений приведены реальная задача
сравнения поз, форматы видео, используемая модель и измеренные технические метрики.
Обучение и коммерческий эффект не заявляются.

Адрес проекта на GitHub: [PROJECT_EASY-MOTION в Enfox/sf_data_science](https://github.com/Enfox/sf_data_science/tree/main/PROJECT_EASY-MOTION).
Для сдачи задания нужно отправить эту ссылку и ZIP-архив презентации через форму курса.
