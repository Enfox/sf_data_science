### Описание проекта

В эпоху развития нейросетей и компьютерного зрения задачи распознавания лиц стали неотъемлемой частью многих сервисов: от поиска по фотографиям до систем безопасности. Современные подходы позволяют достичь высокой точности классификации даже на относительно небольших датасетах за счёт применения **переноса обучения (Transfer Learning)** — техники, при которой предобученные на больших выборках модели адаптируются под конкретную задачу.

В рамках данной работы строится модель глубокого обучения, способная определить личность изображённого человека среди пяти известных технологических лидеров: **Bill Gates, Elon Musk, Jeff Bezos, Mark Zuckerberg, Steve Jobs**.

Проект демонстрирует полный цикл разработки модели компьютерного зрения: от подготовки данных до анализа предсказаний и оценки качества.

### Какой кейс решаем?

Задача формализуется как **многоклассовая классификация изображений (multi-class image classification)** с пятью целевыми классами. На вход модель получает фотографию, на выходе — предсказание класса (имени человека) с вероятностью.

Ключевые вызовы задачи:
- **Дисбаланс валидационной выборки**: некоторые классы представлены значительно меньше других (66 фото у Steve Jobs против ~220 у остальных)
- **Вариативность изображений**: фотографии сделаны в разных условиях освещения, ракурсах, возрастах
- **Ограниченный размер обучающей выборки**: 600 фотографий на класс — относительно небольшой объём для обучения с нуля

Решение этих проблем достигается через применение **Transfer Learning** с предобученной моделью **VGG16** и **аугментацию данных**.

### Этапы работы над проектом

1. **Анализ задачи и подготовка окружения** — определение требований к качеству (`accuracy > 0.85`), настройка PyTorch + CUDA

2. **Загрузка и исследование данных** — анализ распределения классов, проверка размеров и форматов изображений

3. **Препроцессинг изображений** — приведение к единому размеру 224×224, нормализация по статистикам ImageNet, разбиение на батчи через `DataLoader`

4. **Аугментация данных** — применение случайных модификаций (отражения, повороты, изменения яркости) для увеличения разнообразия обучающей выборки

5. **Построение модели** — загрузка VGG16 с предобученными весами, заморозка свёрточной части, замена classifier на новый под 5 классов

6. **Обучение модели** — 10 эпох с оптимизатором Adam, отслеживание метрик на train и validation

7. **Сохранение лучшей модели** — автоматический выбор модели с максимальной accuracy на валидации

8. **Анализ результатов** — построение графиков обучения, матрицы ошибок, визуализация предсказаний

9. **Выводы и рекомендации** — анализ ошибок модели, предложения по улучшению

### Архитектура решения

#### Transfer Learning с VGG16

```
Входное изображение (3 × 224 × 224)
            ↓
┌─────────────────────────────────────┐
│   VGG16 features (ЗАМОРОЖЕНЫ)       │
│   13 свёрточных слоёв + MaxPool     │
│   Извлечение универсальных          │
│   признаков (края, текстуры, формы) │
└─────────────────────────────────────┘
            ↓
   Feature map (512 × 7 × 7 = 25088)
            ↓
┌─────────────────────────────────────┐
│   Новый Classifier (ОБУЧАЕМЫЙ)      │
│   Linear(25088 → 512)               │
│   ReLU                              │
│   Dropout(0.5)                      │
│   Linear(512 → 5)                   │
└─────────────────────────────────────┘
            ↓
   Logits для 5 классов
```

**Ключевые архитектурные решения:**
- **Заморозка свёрток** — экономит вычисления и сохраняет универсальные признаки ImageNet
- **Упрощённый classifier** — 12.8М обучаемых параметров вместо 119М (стандартный classifier VGG16)
- **Dropout(0.5)** — регуляризация против переобучения на относительно небольшой выборке
- **Аугментация** — RandomCrop, HorizontalFlip, Rotation, ColorJitter (только на train)

#### Гиперпараметры обучения

| Параметр | Значение | Обоснование |
|---|---|---|
| Размер изображения | 224 × 224 | Стандарт для VGG16 |
| Batch size | 32 | Оптимум скорость/память |
| Оптимизатор | Adam | Адаптивный lr, работает «из коробки» |
| Learning rate | 1e-4 | Малый lr для бережного обучения |
| Loss function | CrossEntropyLoss | Стандарт для многоклассовой классификации |
| Эпохи | 10 | Достаточно для сходимости classifier |

### Выводы

В рамках проекта была успешно решена задача 5-классовой классификации лиц технологических лидеров с использованием подхода **Transfer Learning**:

1. **Эффективность Transfer Learning** — применение предобученной VGG16 позволило достичь высокой точности (>85%) всего за 10 эпох обучения. Это многократно быстрее и качественнее, чем обучение с нуля.

2. **Заморозка свёрточной части оправдана** — модель ImageNet уже умеет извлекать универсальные визуальные признаки. Адаптация под конкретную задачу через переобучение classifier — оптимальный компромисс скорости и качества.

3. **Аугментация критична для маленьких датасетов** — случайные модификации входных изображений значительно снижают переобучение и улучшают обобщающую способность модели.

4. **Дисбаланс классов влияет на качество** — класс с наименьшим числом примеров (Steve Jobs) демонстрирует более низкую точность. 

5. **Сохранение лучшей модели** — стратегия сохранения весов с лучшей валидационной метрикой защищает от случайного ухудшения качества в последних эпохах.
